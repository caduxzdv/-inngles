CADUSALLERS V3

Esta versão adiciona persistência local em data/store.json, criação de produtos por modal, gerenciamento de estoque, itens de entrega digital, publicação de produtos, carrinho, pedidos e consulta de pagamentos em modo demonstrativo.

Instalação:
1. Faça backup do seu index.js atual.
2. Substitua o index.js pelo CaduSallers_index_v3.js.
3. Mantenha seu .env.
4. Rode: node index.js

O bot cria automaticamente a pasta data e o arquivo data/store.json.
