CaduSallers v2

1. Faça backup do index.js atual.
2. Copie o conteúdo de CaduSallers_v2_index.txt para o index.js do projeto.
3. Mantenha o .env atual. Não altere nem envie o token.
4. Rode: node index.js
5. No Discord, use /panel.
6. Para publicar o painel no canal atual, use /setup.
7. Para testar a loja, use /loja.
8. Para testar compras, use /vercompras.

Esta versão reorganiza o bot em módulos de painel e melhora a experiência de navegação. Dados ainda ficam em memória; banco, pagamento real, entrega, tickets e automações entram nas próximas etapas.
